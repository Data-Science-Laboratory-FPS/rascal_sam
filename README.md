# RASCAL-SAM
## Radiograph Automated Segmentation Comparison and Analysis for Lung — Segment Anything Model

This repository contains the full implementation of the RASCAL-SAM pipeline, which compares three lung segmentation strategies for 30-day in-hospital mortality prediction from COVID-19 chest radiographs:

1. **Expert segmentation** — manual bounding boxes drawn by radiologists
2. **SAM bounding boxes** — automated bounding boxes generated by SAM via Autodotter
3. **SAM pixel-level masks** — automated pixel-level masks generated by SAM via Autodotter

The study uses a DenseNet121 backbone pretrained on MIMIC-CXR and evaluates each segmentation strategy using stratified 4-fold cross-validation, a 30-checkpoint ensemble, and bootstrap 95% confidence intervals.

## Classification Pipeline

### Dataset
- **Source:** Covid Data Save Lives repository (HM Hospitales, Spain)
- **Cohort:** 1,111 frontal CXRs with validated expert bounding box annotations
- **Label:** 30-day in-hospital mortality (98 deceased [class 1], 1,013 survivors [class 0]; ~10:1 imbalance)

### Model
- **Backbone:** DenseNet121 pretrained on MIMIC-CXR (`densenet121-res224-mimic_ch`, torchxrayvision)
- **Input:** Grayscale CXR, 320×320 px
- **Classifier:** Single sigmoid output neuron with Dropout
- **Loss:** BCEWithLogitsLoss with `pos_weight` and log-odds initial bias for class imbalance

### Training
- Stratified 4-fold cross-validation (seed 42)
- Adam optimiser (lr = 1×10⁻⁴, batch size 8, 10 epochs per seed)
- **Ensemble:** 3 random seeds × top-10 checkpoints per seed = **30 checkpoints per fold**
- Threshold selected per fold to maximise balanced accuracy on the validation set

### Evaluation
- Metrics: AUC-ROC, AUPRC, balanced accuracy, sensitivity, specificity, F2-score, F1-score, precision, MCC
- **Bootstrap 95% CI** (n = 1,000 resamples) on concatenated out-of-fold predictions
- Statistical comparison: **DeLong test** and **paired bootstrap** for AUC differences

### Explainability
- **Grad-CAM** applied to `features.denseblock4.denselayer16.conv2` (last convolutional layer)
- Three versions available:
  - Equal-weight ensemble, fold-specific threshold
  - Rank-weighted ensemble, fold-specific threshold
  - Rank-weighted ensemble, fixed threshold ≥ 0.6 (Madrid reference paper criterion)

## Data Setup

Images and clinical files are not included in this repository due to size and data governance constraints. To reproduce the classification pipeline, download the required files from the Covid Data Save Lives repository and organise them as follows:

**1. Download the dataset from:** <https://www.hmhospitales.com/coronavirus/covid-data-save-lives>

**2. Place the files in the project folder with this structure:**
```
project_folder/
│
├── Segmented_images/
│   ├── Segmented_images/
│   │   ├── 1_Experts/        ← expert bounding box segmentations (.jpg)
│   │   ├── 2_SAM_bboxs/      ← SAM bounding box segmentations (.jpg)
│   │   └── 3_SAM_masks/      ← SAM pixel-level mask segmentations (.jpg)
│   │
│   └── discharge_info_cdsl/
│       ├── cxr_discharge_info.csv          ← imaging manifest with outcomes
│       ├── 19_04_2021/
│       │   └── COVID_DSL_01.CSV            ← clinical file (batch 1)
│       ├── 20_07_2020/
│       │   └── CDSL_01.csv                 ← clinical file (batch 2)
│       └── 24_04_2020/
│           └── 01.csv                      ← clinical file (batch 3)
│
├── core_pipeline_v3.py
├── 00_dataset_preparation.ipynb
├── 01_data_organisation.ipynb
├── 02_core_pipeline.ipynb
├── 03_run_experiments.ipynb
├── 04_comparative_metrics.ipynb
└── 05_gradcam.ipynb
```


**3. Run the notebooks in order starting from** `00_dataset_preparation.ipynb`.
The three clinical files (`COVID_DSL_01.CSV`, `CDSL_01.csv`, `01.csv`) are required to reconstruct the 30-day mortality label, as the imaging manifest (`cxr_discharge_info.csv`) does not include discharge dates.
